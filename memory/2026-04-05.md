## 14:40 - TTAi API Model architecture decision

Confirmed project-level architecture direction for TTAi API Model and TTAi Super Model Hybrid:
- `chat.tuetue.vn` = end-user/product chat UI, later extended with login, plans, subscriptions, and user usage/billing views.
- `control.tuetue.vn` = operator/admin dashboard for core/system/model/Ollama/provider management and control-plane actions.
- `api.tuetue.vn` = FastAPI backend core for chat, metering, quota, billing, admin APIs, and future auth/tenant/api-key logic.
- `TTAi Super Model Hybrid` is the core intelligence/backend brain of the whole system and should evolve into Tuệ Tuệ's own model/core over time.
- Decision: do not move quota/billing/core backend logic into WordPress; keep WordPress for public website/content/docs/marketing.
- Boundary rule: `control.*` should be admin UI that consumes backend APIs; `api.*` remains the real control plane/business logic layer.

5. Expand backend config/control APIs for providers, models, health, warm-up, failover, and audit.
6. Build `chat.tuetue.vn` as product surface with login, plans, subscriptions, user usage, and billing pages.
